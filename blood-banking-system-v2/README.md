# Blood Banking System

A blood banking system connects donors with hospitals and blood banks. It manages donor
registrations, tracks blood inventory, and facilitates blood requests during emergencies. The
platform ensures efficient resource management and timely availability of blood.

## Contents
- backend/   -> Node.js + Express + SQLite3 API
- frontend/  -> React app (simple)

## Setup
1. Backend:
   cd backend
   npm install
   npm start

2. Frontend:
   cd frontend
   npm install
   npm start

The backend runs on http://localhost:4000 and the frontend on http://localhost:3000 by default.
